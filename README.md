# Anki Deck Generator

A reusable tool that converts JSON files into Anki deck (.apkg) files.

## Versions

### v2 — Recall (current)
The goal is **active recall**: English on the front, foreign language on the back. The back always includes the foreign spelling (with accent marks / characters), romanization where applicable (pinyin, etc.), and embedded audio pronunciation generated by neural TTS. Cards are structured to build from individual vocabulary words up to full phrases and sentences, so building blocks are learned before the phrases that use them.

### v1 — Recognition
Foreign language on the front, English translation on the back. No audio. Useful for reading/recognition practice.

Both styles can be produced from the same generator — v2 just adds `--audio`.

## Setup

```bash
pip install -r requirements.txt
```

## Usage

### v2 — Recall with audio (recommended)

```bash
python generate_deck.py <input.json> [output.apkg] --audio
```

By default this uses the `zh-CN-XiaoxiaoNeural` voice. For non-Chinese decks, specify the right voice:

```bash
# Spanish
python generate_deck.py decks/recall_500_common_spanish_phrases.json --audio --voice es-MX-DaliaNeural

# Greek
python generate_deck.py decks/recall_conversational_greek.json --audio --voice el-GR-AthinaNeural
```

Run `edge-tts --list-voices` to see all available voices.

### v1 — No audio

```bash
python generate_deck.py <input.json> [output.apkg]
```

If you omit the output filename, it defaults to the input filename with an `.apkg` extension.

---

## Importing into Anki

1. Open the [Anki](https://apps.ankiweb.net/) desktop app
2. Go to **File → Import**
3. Select the generated `.apkg` file
4. The deck will appear in your deck list, ready to study

## JSON Format

### v2 deck (recall + audio)

Front is English, back is the foreign language with spelling and romanization. Prefix the filename with `recall_` by convention.

```json
{
    "deck_name": "Recall My Deck",
    "cards": [
        { "front": "I love you", "back": "我爱你 (wǒ ài nǐ)" },
        { "front": "you're so cute", "back": "你好可爱 (nǐ hǎo kě'ài)" }
    ]
}
```

Generate with:
```bash
python generate_deck.py decks/recall_my_deck.json --audio --voice zh-CN-XiaoxiaoNeural
```

### v1 deck (recognition, no audio)

```json
{
    "deck_name": "My Deck",
    "cards": [
        { "front": "我爱你 (wǒ ài nǐ)", "back": "I love you" },
        { "front": "Question or prompt", "back": "Answer" }
    ]
}
```

### Optional fields

| Field | Description | Default |
|---|---|---|
| `deck_id` | Stable numeric ID for the deck | Auto-generated from `deck_name` |
| `model_id` | Stable numeric ID for the card model | Auto-generated from `model_name` |
| `model_name` | Name for the card template | `"{deck_name} Model"` |
| `css` | Custom CSS for card styling | Clean centered layout, 24px font |

### Encoding

The generator handles UTF-8 natively — accented characters (é, ñ, ü), Chinese characters (爱, 心), pinyin tone marks (ài, xīn), Greek (αγαπώ), and any other Unicode work without extra configuration.
